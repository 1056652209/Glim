Mermaid, an expanded JSON tree, and a Git diff. These workspace features are
available in release 0.1.11 on macOS and Windows; the captures use macOS.

composited into the captures. They do not demonstrate unreleased native preview
or updater changes. Use non-sensitive sample files when refreshing these images.

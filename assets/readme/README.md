# README artwork

The file-format wall is generated by `python3 scripts/generate-format-wall.py`. It embeds existing Material Extensions file icons and purpose-made category glyphs so GitHub can render it without external images or scripts. Their MIT notice is embedded in each SVG; the source license is retained in [file-icons/LICENSE](../file-icons/LICENSE).

`formats.svg` and `formats-dark.svg` contain the same representative formats. `*` marks macOS-only previews; `†` marks limited previews. The wall is an overview, not a promise of complete rendering for every format. Keep it aligned with [format support](../../docs/file-format-support.md).

The download-button SVGs link to the current release from each README.

用户要求暂停此项工作，恢复前不要继续扩展边界迁移。当前已实现部分已随 0.2.2 交付，但全部边界尚未迁移完成。本页维护当前实现状态和剩余工作；完整发布说明见 [GitHub Release](https://github.com/NeoPanic/Glim/releases/tag/v0.2.2)。

## 配置与清单状态

- 唯一数值入口：[assets/reader-limits.json](../assets/reader-limits.json)。Rust、Swift 和图表 JavaScript 使用同一配置生成的策略。
- 原始清单为 31 类、175 项；新增 `io.buffer_bytes`、`io.cache_bytes`、`svg.event_bytes` 和 `remote_image.minimum_bytes_per_second` 四项工作预算后，当前为 **33 类、179 项**。
- 配置中 54 项标为取消总量门槛（`unlimited`），23 项为后备视图（`fallback`），8 项为分页（`page`），48 项为工作预算（`budget`），8 项为超时策略（`timeout`）；仍有 22 项拒绝（`reject`）和 16 项截取显示（`truncate`）。这些是配置效果统计，不能作为实现完成率或全部行为正确的证明。
- [英文清单](reader-limits.md)和[中文清单](reader-limits.zh-CN.md)已同步当前配置。后续修改配置值后仍须执行 `python3 scripts/generate-reader-limits.py --docs`。
- 中文清单的“实际行为”列仍主要使用英文说明；生成器尚未采用配置中已有的 `description_zh`，中文说明补全仍是待办。

## 已实现、仍需整体复核

- UTF-8 可编辑分页，固定缓冲区复制未修改范围并原子保存；二进制十六进制分页。
- 流式报告：压缩包、可执行文件、NumPy、safetensors；Gzip/Bzip2/Xz 使用按需解码和滚动缓存。
- CSV 行列分页与完整单元格查看；JSON 树预算保留，完整源文本可访问。
- SQLite 快照取消总大小门槛，表/列/行分页、完整值查看、延长查询时间。
- MKV 文件流读取、磁盘时间戳索引、fragmented MP4 输出；按播放项启动可取消的准备进程。
- ImageIO 图片按页预览，QOI 流式转换，GIF 文件解码与画布采样；远程图片下载至临时文件；SVG 流式清理。
- 原生缩略图准备对可识别尺寸的图片避免放大小图；浮点图片由原生路径执行色彩转换。
- 字体、播放列表、书签、会话总量门槛移除；工作区搜索和最近列表有继续入口。
- XMind 容器总大小/条目门槛移除，复杂预览预算改为完整 JSON/XML 源分页后备；新 ZIP member 按需 Stored/Deflate 解码带 CRC/长度校验。
- OBJ/STL/BDF 超过静态投影预算时提供完整源分页，BDF 不再静默只展示前一组字形。

## 恢复时重点复核

- 分页保存后刷新保持当前页、撤销历史和光标；文件缩小后不要自动替换阅读器。
- 压缩流取消后解码器状态、缓存淘汰和向前/向后翻页、ZIP 完整性校验。
- ZIP member 当前按需解码支持 Stored/Deflate；CRC 和长度一致性检查在解码到末尾时完成。
- XMind serde 深度与 XML 结构预算是否全部正确进入后备路径。
- 大 ZIP 的中央目录仍由 zip crate 整体索引；报告多数仍需生成完成才显示首屏。
- fragmented MP4 未实际播放验证；隐藏标签页时准备进程是否应取消。
- ImageIO 原图仍非真正分块解码；大型 SQLite 单值仍一次性载入。
- 大型表格/电子书不能只取消限制后整体载入内存，需要分页/增量方案。
